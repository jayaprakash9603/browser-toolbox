Device frame artwork in this folder is processed from transparent mockup PNGs
bundled with the extension (originally from WebMobileFirst / Mobile FIRST downloads).
Empty screen areas are punched to alpha and scaled to 760px width for the responsive viewer.

Re-run: python scripts/import-phone-mockups.py

---

CSS chassis fallback (island, home indicator, radii) follows geometry from:

mobile-device-frames (https://github.com/phucsystem/mobile-device-frames)
