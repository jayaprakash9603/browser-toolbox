# Mobile Simulator — asset license inventory

| Asset | Path | License | Notes |
|-------|------|---------|--------|
| Device frame WebPs | `public/simulator/frames/*.webp` | MIT | [open-device-frame](https://github.com/SinaKarimi7/open-device-frame) |

| Overlay icons | `overlayIcons.ts` | One Panel original | Lucide-compatible stroke SVG paths (ISC Lucide) |
| Custom SVG / CSS bezels | Inline in `frames.tsx` | One Panel original | Used when no MIT WebP is mapped |

## Prohibited in committed source

- WebMobileFirst / Mobile Simulator extension device PNGs or derived WebPs
- icomoon font vendored from the reference extension
- URLs or branding pointing at webmobilefirst.com in product UI

## Adding new frames

1. Confirm upstream license permits redistribution in a Chrome extension.
2. Add files under `public/simulator/frames/` and update `scripts/vendor-device-mockups.py` `ASSETS` map.
3. Run `npm run simulator:vendor-frames` then `npm run simulator:frames`.
4. Record the source in this file.
